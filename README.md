# Joshua Estrema — portfolio starter

Open index.html in a browser. No installation or build step is required.

## Edit
- index.html: homepage and featured screenplay.
- writing.html: Life Unsealed and its project details.
- audio.html: audio short story and transcript space.
- video.html: reserved blank video space.
- about.html: introduction, motivation, skills, portrait.
- styles.css: shared colors, typography, spacing, mobile layout.
- assets/: real portrait, screenplay preview, screenplay PDF, audio export.

The supplied personal and project wording has been preserved. Video, extra screenplay details, and the audio transcript are intentionally unfinished. This is a restrained starter preview, pending a fuller design discussion. The new introduction, skills, and motivation are used exactly as supplied; no achievements, project roles, or outcomes were invented. Existing project descriptions were carried over verbatim.

To add video later, replace the empty-screen div in video.html with a video element using controls, preload="metadata", and a relative source such as assets/video.mp4. Supply captions or a transcript. Add your own project title and explanation.

## GitHub Pages
Upload the contents of this ZIP directly to the repository root, preserving assets/. In repository Settings > Pages, choose Deploy from a branch and select the main branch and root folder. Save. If your branch has another name, select that branch instead.

The separate standalone preview file contains embedded copies of the media; it is for reviewing the design. Edit and publish these readable source files instead. Publication has not been performed.
